# Optimal Control of Multi-Area Power Systems

B.Tech Project (BTP): load frequency control (LFC) of interconnected power systems with PID controllers, in MATLAB and Simulink.

A one-page summary of results is in [`report/LFC_results_one_page.pdf`](report/LFC_results_one_page.pdf).

## System

Two identical non-reheat thermal areas joined by a tie-line. Step load of 0.05 pu in Area 1. One PID per area acts on the area control error, ACE = ΔPtie + β·Δf.

| Parameter | Value | Parameter | Value |
|---|---|---|---|
| Tg | 0.08 s | 2π·T12 | 0.545 |
| Tt | 0.3 s | β = 1/R + 1/Kp | 0.425 |
| Tp | 20 s | f0 | 50 Hz |
| Kp | 120 Hz/pu | PID filter N | 100 rad/s |
| R | 2.4 Hz/pu | Step / length | 0.01 s / 100 s |

All values live in [`models/params/lfc_params.m`](models/params/lfc_params.m).

## Results (two areas, linear model)

| Controller | KP / KI / KD | ITAE | min Δf1 (Hz) | ts Δf1 (s) | final Δf1 (Hz) |
|---|---|---|---|---|---|
| Droop only | 0 / 0 / 0 | 713.25 | -0.1117 | 8.75 | -0.0588 |
| Integral | 0 / 0.5 / 0 | 0.827 | -0.1089 | 13.5 | 0 |
| Manual PID | 0 / 0.5 / 0.1 | 0.482 | -0.0950 | 6.3 | 0 |
| pidtune PID | 0 / 0.849 / 0 | 1.882 | -0.1072 | 22.0 | 0 |

Integral control is stable for KI < 1.3847. The Simulink model matches the linear model to 1e-7 Hz.

## Repository layout

```

  params/       lfc_params.m               all parameters
  core/         build_lfc_plant.m          linear N-area plant (state-space)
                build_lfc_closed_loop.m    plant + one PID per area
                simulate_lfc_linear.m      step-load simulation
                build_lfc_simulink.m       generates models/simulink/lfc_2area.slx
                simulate_lfc_simulink.m    runs the Simulink model
  analysis/     lfc_metrics.m, log_result.m, read_results_log.m,
                plot_compare.m, plot_style.m, format_figure.m
  scripts/      one script per step (phase0_*, phase1_*, phase2_*, phase3_*)

  archive/      old files kept for history (see archive/README.md)

references/     reference books, thesis and course scripts
results/        figures/ (fig_1 ... fig_8), data/, results_log.csv, progress.md
report/         one-page summary (PDF) and the script that builds it
setup_paths.m   adds all folders to the MATLAB path
```

## Running

From the repository root, in MATLAB:

```matlab
setup_paths
phase0_baseline       % droop-only baseline
phase1_ki_sweep       % integral gain sweep
phase3_manual_pid     % manual PID tuning
phase2_validate       % Simulink vs linear model
```

or from a terminal: `matlab -batch "setup_paths; phase0_baseline"`.
Rebuild the Simulink model with `build_lfc_simulink(2)`.

## Requirements

MATLAB R2020a or later with Control System Toolbox and Simulink. Developed on R2026b.
